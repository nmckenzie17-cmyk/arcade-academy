## Goal

Integrate the game completely with Arcade Academy.

The game must support:

1. Student vs Student using the existing Firebase multiplayer system.
2. Student vs Class-Calibrated Computer without requiring another student or Firebase room.

Use Tic-Tac-Toe and Thinking Tanks as implementation references.

Preserve the new game’s core mechanics and visual identity, but align its authentication, questions, AI, statistics, home screen, Firebase architecture, Hub presentation and responsive behaviour with the existing collection.

Implement and verify the integration rather than only reviewing it.

## Architecture

Online multiplayer must follow:

Game
↓
MultiplayerManager
↓
FirebaseManager
↓
Firestore `/matches`

Questions must follow:

Game
↓
MultiplayerQuestionHelper / QuestionManager
↓
Student’s Hub-selected question bank

AI calibration must follow:

Game
↓
Shared AI Difficulty Manager
↓
FirebaseManager
↓
Privacy-safe class statistics

Do not put direct Firebase Auth or Firestore calls inside the game.

Do not create a second Firebase configuration.

## Authentication

Reuse the existing Firebase Authentication session.

If the player is not signed in:

- Do not create an anonymous account
- Do not create another login screen
- Direct the player back to Arcade Academy to sign in

Use the student’s existing profile display name and assigned class.

## Online Multiplayer

Use the existing `/matches/{roomCode}` architecture.

Support the appropriate states:

- `waiting`
- `lobby`
- `playing`
- `finished`
- `abandoned`

Room codes must:

- Be five digits
- Be collision-safe
- Permit direct lookup without permitting collection listing
- Reuse abandoned or stale rooms only through FirebaseManager

Store only the information required for the match. Do not copy full profiles, emails, class statistics or educational histories into match documents.

## Online Questions

Use MultiplayerQuestionHelper and QuestionManager.

If the host selects a question format:

- Save it in the match settings
- Validate it against the supported formats
- Apply the same match rule to both players

Each human student must use their own Hub-selected class code and question bank.

Player A must not inherit Player B’s class code or questions.

Show a clear error when:

- A class code is missing
- The selected format is unavailable
- A question bank cannot be loaded
- An older room lacks required question settings
